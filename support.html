When reporting a problem

Please include the following information:

  • Your iPhone or iPad model
  • Your iOS version
  • The game version
  • A short description of the problem
  • A screenshot or screen recording, when possible

Common troubleshooting

  • Restart the game and try again.
  • Make sure you are using the latest game version.
  • Restart your device if the problem continues.
  • Ads require an internet connection, while the main gameplay can be played offline.
